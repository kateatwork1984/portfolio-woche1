# Mein Portfolio - Kate

## Beschreibung
Dies ist meine erste Portfolio-Webseite (Woche 1).
Sie enthält Informationen über mich, eine Skills-Liste und ein Kontaktformular.

## Verwendete Techniken
- HTML5 (semantische Elemente: header, nav, main, section, footer)
- CSS (Grundstyling, Flexbox in der Navigation, Hover-Effekte)
- Responsive Design (Media Query für kleine Bildschirme)

## Weg
Ich habe Weg B (geführt) gewählt.

## Notizen
